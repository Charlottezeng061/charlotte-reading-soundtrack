Dynamic Reading Soundtrack

About the project

A browser-based audio instrument that lets readers combine a book genre with an atmosphere to create their own reading soundtrack.

Open the finished instrument

Project overview

This project explores how readers can shape background sound as the mood of a story changes. Readers choose two audio layers, preview different recordings and play a combination that suits their reading.

The aim is to support immersion through a small number of choices. Once a soundtrack is playing, readers can return to their book and adjust it when they feel the atmosphere has changed.

Design scenario

Dynamic Soundtrack-er

The scenario asks for an ongoing soundtrack for an activity or environment, shaped by occasional but meaningful user input. I apply this to reading, where a story can move between different moods while the reader's attention remains on the book.

My response centres on reader agency: readers decide how a scene feels and express this through their sound choices. For example, they might keep Fantasy selected while changing the atmosphere from Calm to Dark as a chapter becomes more tense.

This connection between interpretation and input makes the soundtrack personal. The same book can lead to different sound combinations for different readers.

From concept to final instrument

My initial concept explored a continuously evolving soundtrack with changes in rhythm, texture and atmosphere. Through prototyping, I narrowed this into a more manageable interaction: combining two recorded audio layers.

The six prototypes in Assignment 2 explored soundtrack control and guidance. They helped me consider both how users choose sounds and how the interface explains those choices.

The final approach combines direct selection, short previews and controlled randomness. Each category contains four recordings, giving readers variation within a manageable set of controls.

Core interactions

Select and preview

Readers choose one genre and one atmosphere. Genres include Fantasy, Mystery, Romance and Sci-Fi. Atmospheres include Calm, Dark, Magical and Nostalgic.

A single click selects a category and plays a preview of up to six seconds. Double-clicking the same button moves to its next recording. “Sound 1 / 4” identifies the selected recording, while the filled button background identifies the selected category.

Play and adjust

Play starts both selected layers together and changes to Pause during playback. The volume slider adjusts overall loudness. The display above the selections shows the current combination and playback status.

Random, Repeat and Reset

Random changes the recordings within the selected categories. Repeat loops both layers independently. Reset stops playback, restores Fantasy and Calm, returns every category to its first recording, sets volume to 50% and turns Repeat off.

Extended technique: Random

Controlled randomness lets readers explore variation while keeping their chosen mood. For each selected category, Random chooses one of the other three recordings. The genre and atmosphere stay selected. 

function randomClip(currentClip) {
  // Move forward by one, two or three clips.
  const offset = Math.floor(Math.random() * 3) + 1;

  // Wrap the result back to a clip number from 1 to 4.
  return ((currentClip - 1 + offset) % 4) + 1;
}

Math.random() and Math.floor() produce an offset of 1, 2 or 3. The remainder operator wraps the result into the four available clip numbers. Excluding an offset of zero ensures the recording changes whenever Random is used.

This supports the concept by keeping broad decisions with the reader while allowing the instrument to suggest a different sound combination.

How the code supports the interaction

The instrument uses HTML, CSS and vanilla JavaScript. HTML provides the sound buttons, playback controls, volume slider and guide. CSS handles layout, themes and visual states. JavaScript connects these controls to audio playback and updates the interface.

The selected genre and atmosphere are stored as variables. A separate collection stores the current clip number for each category. Keeping these values separate allows Random to change the recording without changing the selected category.

Two Audio objects play the soundtrack layers, while a third handles previews. The preview can therefore play one recording independently. The volume slider converts its percentage into a value between 0 and 1 for the audio volume property.

Click and double-click need separate handling. A short delay allows the code to distinguish a single click from the beginning of a double-click, helping prevent conflicting preview and clip-change actions.

Design system

Color and typography

Warm brown (#3f2e11) and beige (#dfd4b8) create a quiet visual setting for reading. Day and night modes reverse the background and foreground colours without changing the sound selections.

Fraunces gives the title a literary character. Outfit is used for buttons and supporting text to keep repeated controls easy to scan.

Buttons and feedback

Rounded sound buttons use consistent spacing, borders and corner radii. A filled background identifies the selected genre and atmosphere, while the small sound counter shows the recording selected within each category.

Play is the main action and sits in the centre of the player controls. Volume is visually smaller, while Random, Reset and Repeat are grouped as supporting actions.

Icons reduce the space needed for familiar actions such as playback, volume and theme switching. Accessible labels identify controls that do not have visible text.

Responsive behaviour

On larger screens, the sound categories use four columns. The playback area places volume, Play and the supporting controls across one row.

On smaller screens, the sound buttons change to two columns and the playback controls rearrange vertically. This keeps the buttons readable without squeezing every control into a narrow row.

Day and night modes provide an additional visual preference. Changing the theme does not change the selected sounds.

Reflection

The main challenge was balancing a quiet reading interface with interactions that users could discover. Removing visible text made the page simpler, but also made the double-click interaction harder to understand. The step-by-step guide provides an explanation without keeping a long instruction on screen.

The final instrument gives readers a small set of meaningful choices. Controlled randomness adds variation, while persistent selections keep the reader in control of the overall atmosphere.

A limitation is that double-click is less familiar on touchscreens. A future version could provide a visible next-sound control. Audio transitions could also be refined with fades; these are not included in the current version.

Peer testing showed that the double-click instruction was easy to miss, so I introduced a step-by-step guide. Teacher feedback also led me to clarify “1 / 4” as “Sound 1 / 4” and reduce the visual emphasis of the volume control.
